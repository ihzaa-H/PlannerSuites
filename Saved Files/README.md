# Saved Files

This is the home for everything you create with the Planner Suite.

| Folder | What goes here | Made by |
|--------|----------------|---------|
| **Diagrams/** | `.flow` flowchart files | FlowForge → 💾 Save |
| **Boards/** | `.board` whiteboard files | IdeaBoard → 💾 Save |
| **Exports/** | `.png` / `.svg` images | Any tool → 🖼 Export |

## How saving works

The tools run in your web browser, so **Save** and **Export** hand the file to the
browser, which downloads it. Two easy ways to land files here:

1. **Best — turn on "Ask where to save each file" in your browser**
   (Chrome/Edge: Settings → Downloads → toggle *Ask where to save each file before downloading*).
   Then each Save/Export shows a dialog where you pick this folder.
2. **Or** just let files go to your normal *Downloads* folder and move them here afterwards.

## Reopening

- FlowForge → **📂 Open** → pick a file from `Diagrams/`
- IdeaBoard → **📂 Open** → pick a file from `Boards/`

Everything stays on your computer — nothing is uploaded anywhere.
